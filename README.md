# Progetto OMNeT++

Questo repository raccoglie appunti, materiale didattico, esercitazioni e script relativi alla modellazione e simulazione di reti utilizzando il framework [OMNeT++](https://omnetpp.org/). 

## Tecnologie e Linguaggi Utilizzati

* **OMNeT++ (NED)**: Per la definizione della topologia di rete.
* **Python**: Utilizzato come linguaggio principale per gli script di automazione e configurazione.
* **Mako**: Motore di template (basato su Python) per generare file di testo dinamicamente.
* **JSON**: Per il parsing strutturato dei dati di input.
